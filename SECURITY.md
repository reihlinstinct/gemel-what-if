# Security policy

Report vulnerabilities privately through GitHub's "Report a vulnerability" (private advisories) on this repository.

This project is a static page with no server and no user accounts. Rules that keep it that way:
- No personal financial data, balances or real stories in the repo (`stories/` is git-ignored).
- No secrets in code; the data script reads only public open data.
- GitHub Actions use read-only permissions and pinned versions.
